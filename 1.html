2월-1

1

약속이 있으신가요?


문장 구조
이 문장은 **일반동사 의문문 (Yes/No question)**이에요.
Do → 조동사, 현재시제 일반동사 의문문 만들 때 사용
you → 주어
have → 동사, “가지고 있다”
an appointment → 목적어, “약속”
즉 구조는:Do + 주어(you) + 동사(have) + 목적어(an appointment)?
1️⃣ 기본 의미
a / an = 한 개의 / 하나의라는 뜻, 불특정 명사 앞에 씀
단수 명사 앞에만 사용 가능
2️⃣ a vs an 구분
a → 자음 소리로 시작하는 단어 앞
예: a book, a car, a university*
⚠️ “university”는 글자는 모음(u)이지만 발음은 /juː/ → 자음 소리라 a
an → 모음 소리로 시작하는 단어 앞
예: an apple, an orange, an hour*
⚠️ “hour”는 h는 발음 안나고 /aʊər/ → 모음 소리라 an

즉 구조는:주어(I) + 동사(have) + 목적어(a meeting) + 전치사구(with Mr. Kim)

김 대표님은 다음 주 화요일에 시간 괜찮으세요?


1️⃣ 문장 구조 분석
Is → 동사, 여기서는 be동사
Mr. Kim → 주어
available → 형용사, 보어(주격보어) 역할
next Tuesday → 시간 부사구
즉, 구조는 Be동사 + 주어 + 보어 형태입니다.
2️⃣ “available”이 형용사로 쓰이는 이유
“available”은 원래 형용사로 사용 가능하다, 시간이 있다, 응답할 수 있다 의미
Be동사와 함께 쓰이면 주어의 상태나 가능성을 묘사합니다.
예시:
She is available now. → 그녀는 지금 가능하다.
The room is available. → 방이 비어 있다 / 사용할 수 있다.
포인트:
Be동사 + 형용사 = 주어의 상태 설명
“Mr. Kim is available” = “김 선생님은 (그 시간에) 가능하다”
3️⃣ 의문문 만들기
Be동사 의문문: Be + 주어 + 보어?
Is Mr. Kim available next Tuesday? ✅
Do/Does 같은 조동사 필요 없음, 이미 Be동사 사용
영어에서 **Be동사(is/am/are)**는 상태나 존재를 나타낼 때 쓰여요.
그런데 “is + 주어 + 동사원형” 구조는 보통 의문문이나 조동사 없이 간단히 동작을 나타낼 때 조금 특별하게 쓰여요.
예시: Is he coming?
해석: “그가 오고 있나요?”
구조: Is + he(주어) + coming(동사원형/현재분사)
Is she ready?
해석: “그녀는 준비됐나요?”
구조: Is + she(주어) + ready(형용사/현재분사)
현재분사( Present Participle )란? 영어에서 동사 + -ing 형태를 말해요.
동작이 진행 중임을 나타낼 때 주로 쓰여요.
2. 현재분사 용도
진행형 시제 만들기
현재진행형: be동사 + 현재분사
예: I am eating lunch. → 나는 점심을 먹고 있어요.
He is reading a book. → 그는 책을 읽고 있어요.
형용사처럼 쓰이기
사람/사물의 상태를 설명할 때
예: The running water is cold. → 흐르는 물은 차가워요.
A boring movie → 지루한 영화
분사구문 만들 때
문장을 줄여서 자연스럽게 연결
예: Walking down the street, I saw my friend. → 길을 걷다가 친구를 봤어요.
3. 요약
현재분사 = 동사에 -ing 붙인 형태
진행 중인 동작 나타낼 때
형용사처럼 상태를 설명할 때 / 문장을 연결할 때

그는 오후 3시는 가능합니다.


문장 구조
이 문장은 주어 + Be동사 + 보어 + 부사구 구조의 평서문이에요.
주어 (Subject): He → “그”
Be동사 (Verb: be): is → 주어의 상태/존재를 나타냄
보어 (Complement): available → 형용사로 주어의 상태 설명
부사구 (Adverbial phrase): at 3 p.m. → 시간 정보
즉, 문장 구조는: [주어] + [Be동사] + [형용사] + [부사구]
🔹 be동사 + available 뜻
👉 ~이 가능하다 / 👉 ~이 이용 가능하다 / 👉 시간이 된다
구조 : 주어 + be동사 + available
예문
1️⃣ I am available tomorrow. → 나는 내일 시간 돼.
2️⃣ The manager is not available now. → 매니저는 지금 자리에 없습니다. (통화 불가 느낌)
3️⃣ Rooms are available. → 방 이용 가능합니다.

그 시간이 당신에게 맞을까요?


Would → 조동사, 공손하게 가능 여부나 제안을 물을 때
that → 가리키는 것, 앞에서 말한 시간이나 계획
work → 동사, ‘적합하다 / 잘 맞다 / 괜찮다’
for you → 전치사구, ‘당신에게’
즉 구조는:Would + 주어(that) + 동사(work) + 전치사구(for you)?
1️⃣ 주어가 누구인가?
that = 앞에서 말한 시간이나 계획 (예: 3 p.m. 약속)
즉, that = 단수 3인칭
me는 목적격이기 때문에 주어가 아님 → 동사 뒤에 s 붙는 것과 관련 없음
2️⃣ 동사 s 붙는 이유
영어 현재형 규칙:
주어 현재형 동사
I → work
you → work
he / she / it / that → works
we / they → work
여기서 that = it = 단수 3인칭이므로 works가 맞음
